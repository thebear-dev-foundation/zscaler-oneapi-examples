# Changelog

## [0.1.0] — 2026-04-24

### Added
- Getting-started guide — OneAPI authentication (Client Secret, JWKS URL, certificates), base URLs, API examples.
- Command reference — `curl` examples for Cloud & Branch Connector (`/ztw/api/v1/*`) and ZIA (`/zia/api/v1/*`): forwarding rules, EC groups, activation, firewall, URL filtering, SSL inspection, IP groups, locations, workload groups, DNS/IPS.
- Troubleshooting — token expiry, rate-limit handling, activation mismatches, GWLB target health from the AWS side.
- `scripts/probe-endpoints.py` — read-only discovery of resource shapes + supported methods across ZIA + ZTW.
- Example shell scripts for common GET queries.
